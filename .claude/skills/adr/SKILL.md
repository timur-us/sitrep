# ADR

File: `docs/decisions/NNNN-short-title.md`, next free number. Sections: Status (proposed / accepted / superseded by NNNN) · Date · Context (the problem, the constraints, what Project 1 taught) · Options (each with a sentence on what it would cost us) · Decision · Consequences (what gets easier, what gets harder, what to watch) · Sources (links, dated).

Keep it under one page. Name the trade-off honestly; an ADR without a downside is not finished. Link the ADR from the PR description and, if it changes behaviour, from README.
